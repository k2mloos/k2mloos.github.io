What this app does

"k2mloos Gitea Backup" is a personal OAuth client used with rclone to upload backup files of the owner's self-hosted Gitea server to the owner's own Google Drive.

Data access

  • The app accesses only the Google Drive of the account that authorizes it, which is the owner's own account.
  • It is used only to create, read and manage the backup files it uploads.
  • No data from any other user is collected, stored or processed.

Data sharing

No data is sold, shared with or transferred to third parties. OAuth tokens are stored only on the owner's own server.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
